# FUTURE_DS_02
📊 Customer Retention and Churn Analysis Dashboard (Power BI)

📌 Project Overview

This project is an interactive Customer Retention and Churn Analysis Dashboard developed using Power BI as part of my Future Interns Data Science & Analytics Internship.

The dashboard helps analyze customer behavior, identify churn patterns, and understand the factors affecting customer retention. It provides valuable business insights through interactive visualizations and KPI metrics.


---

🎯 Objectives

Analyze customer churn behavior

Identify factors affecting customer retention

Compare churn rates across services and payment methods

Study customer tenure and contract impact

Build interactive dashboards for business insights



---

📊 Dashboard Features

🔹 Key Performance Indicators (KPIs)

Total Customers

Churn Customers

Customer Tenure

Churn Rate



---

🔹 Visual Insights

📈 Churn Rate by Internet Service

👥 Gender-wise Churn Analysis

📊 Customer Tenure Analysis

👴 Senior Citizen Churn Analysis

🚀 Key Insights

Customers with month-to-month contracts show higher churn rates

Fiber optic users contribute significantly to churn

Customers using electronic check payments have higher churn probability

Longer customer tenure is associated with better retention



---

✅ Conclusion

This dashboard effectively analyzes customer retention and churn patterns using interactive Power BI visualizations. It helps identify key factors influencing customer behavior and supports data-driven business decisions.
